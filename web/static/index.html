Lexical Analysis

Tokens produced by the hand-written DFA scanner (IPv4 and CIDR literals are recognised inside the scanner).

Syntax / IR

Rules after recursive-descent parsing and semantic lowering: one inclusive range per packet field (shown as text and as the integer the automata use).

Interval Partitions

Each field's domain is cut at every rule boundary into the minimal set of disjoint intervals. Each interval is one alphabet symbol, like a character class in flex. Hover over a segment to see its range and the rules that cover it.

Automata

Thompson ε-NFA, layered DFA from the subset construction, and the Hopcroft-minimized DFA.

Minimize by
Compile to see the automata.

Analysis Dashboard

Shadowing and redundancy, computed by a separate analysis pass over the unminimized DFA (each final state records every matching rule and the winner). Redundancy is proved with the equivalence checker.

Packet Tester

Classifies a packet with the minimized DFA, explains it with the unminimized DFA, and cross-checks it with the linear first-match oracle.

Original vs Optimized

The optimizer only removes rules. Shadowed rules go first, then each remaining rule from last to first is removed only if every packet class (final DFA state) keeps its original decision. The result is then proven equivalent to the original by the product-automaton check.
